# Data folder

Semua layer di sini masih demo/mock supaya project bisa langsung dibuka di browser.

Tambahan terbaru:
- `places.json` dipakai untuk fallback suggestion lokasi kalau API key Geoapify belum diisi.
- Kalau mau realtime suggestion, isi `APP_CONFIG.geocoder.apiKey` di `js/config.js`.
- Tombol `Pakai lokasi saya` tidak butuh API tambahan, cukup izin lokasi dari browser.
